# 취급 지침: 급성 독성 물질 (GHS06)

보호구: 보안경, 물질에 맞는 내화학 장갑(필요 시 이중 착용), 실험복, 흄후드 필수
1. 반드시 흄후드 안에서만 개봉하고 사용한다.
2. 피부 흡수가 가능하므로 장갑이 오염되면 즉시 교체한다.
3. 혼자 작업하지 않고, 사용 물질과 응급조치 방법을 동료에게 알린다.
4. 작업 후 손을 씻고, 실험실 안에서 음식물을 섭취하지 않는다.
보관: 잠금 가능한 지정 장소에 보관하고 사용량을 기록한다.
폐기: 독성 폐기물로 표시해 따로 모으고 지정 업체에 처리를 맡긴다.
사고 시: 노출되면 증상이 없어도 즉시 의료기관에 연락하고 SDS를 함께 보여준다.
